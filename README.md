# 废土之旅

一个仿照《俄勒冈之旅》(The Oregon Trail) 的文字冒险游戏。

核战争已经过去二十年了。你被赶出了密苏里州独立城地下的避难所, 要一个人开车沿着当年拓荒者走过的俄勒冈小道, 去 3,119 公里 (1,938 英里) 外的俄勒冈城。

## 怎么运行

需要 Python 3.6 或更高版本, 不用装任何别的东西。

```bash
python3 wasteland_trail.py
```

## 玩法

- 开局可以选距离单位: 公里或英里
- 一个人出发。路上每个据点都有一个人愿意跟你走, 带不带由你决定, 队伍最多 4 个人
- 每个愿意加入的人都有职业和特长: 老兵、医生、机械师、猎人、商人、拾荒者。特长只要人还活着就一直有用, 但多一个人也要多吃多喝
- 出发前在营地买食物、水、燃料、子弹、零件和药品, 路上的据点也能补货
- 每天选择: 继续前进、休息、搜刮废墟、打猎、用药、改变口粮或速度
- 车有慢、中、快三档: 开得越快越费燃料、越颠簸, 开得越慢路上耗的天数越多
- 路线和距离按 1847 年拓荒指南里的真实路程表: 路上会经过烟囱岩、独立岩、南山口等 17 个真实地标, 还有卡尼堡、拉勒米堡等 6 个当年的贸易站和军事堡垒可以补给。状态栏会显示下一站还有多远
- 天气每天都会变: 酷热要多喝水, 沙尘暴开得慢, 酸雨天待在外面会受伤
- 打猎是个小游戏: 屏幕上出现一个词, 打得越快, 得到的肉越多
- 路上会遇到劫匪、变异野兽、雷区、陌生人、神秘无线电等随机事件
- 随时可以存档 (主菜单选 8), 下次打开游戏接着玩。一局结束后存档会自动删掉

## 结局

一共有 6 个结局: 完美结局、独行结局、普通结局、孤独结局、全军覆没, 还有一个很难触发的隐藏结局。

## 自己改游戏

`wasteland_trail.py` 最上面的「游戏设置」里的数字都可以随便改, 比如总路程、一开始的钱、商店价格、天气出现的机会。

想加新的随机事件, 就照着已有的事件写一个函数, 再把它放进 `EVENTS` 列表里。
