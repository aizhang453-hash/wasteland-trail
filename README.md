# 废土之旅

一个仿照《俄勒冈之旅》(The Oregon Trail) 的文字冒险游戏。

核战争已经过去二十年了。你要带着队伍开车穿过废土, 在冬天到来之前赶到 1000 公里外的安全城市。

## 怎么运行

需要 Python 3.6 或更高版本, 不用装任何别的东西。

```bash
python3 wasteland_trail.py
```

## 玩法

- 出发前在营地买食物、水、燃料、子弹、零件和药品, 路上的据点也能补货
- 每天选择: 继续前进、休息、搜刮废墟、打猎、用药、改变口粮或速度
- 天气每天都会变: 酷热要多喝水, 沙尘暴开得慢, 酸雨天待在外面会受伤
- 打猎是个小游戏: 屏幕上出现一个词, 打得越快, 得到的肉越多
- 路上会遇到劫匪、变异野兽、雷区、陌生人、神秘无线电等随机事件
- 第 50 天冬天就来了, 一定要在那之前赶到
- 随时可以存档 (主菜单选 8), 下次打开游戏接着玩。一局结束后存档会自动删掉

## 结局

一共有 6 个结局: 完美结局、普通结局、孤独结局、全军覆没、核冬天, 还有一个很难触发的隐藏结局。

## 自己改游戏

`wasteland_trail.py` 最上面的「游戏设置」里的数字都可以随便改, 比如总路程、一开始的钱、商店价格、天气出现的机会。

想加新的随机事件, 就照着已有的事件写一个函数, 再把它放进 `EVENTS` 列表里。
